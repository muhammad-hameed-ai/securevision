Capabilities

Everything a security system needs

Multiple AI models run together in real time on the device's camera feed.

🟢

Face Recognition

Recognises enrolled people by name with a live confidence score, using FaceNet-512 embeddings and mandatory 5-point facial alignment.

🟠

Weapon Detection

A YOLOv8 model — trained from scratch on a public weapons dataset — flags weapons in frame and raises a critical alarm.

🔴

Unknown Alerts

Any unenrolled face is flagged, logged, and alarmed, with an automatically captured snapshot attached to the alert.

🟡

Motion Sensing

Frame-differencing motion detection with intensity metering and smart debouncing to avoid alert storms.

🔔

Graded Alarms

Three severity tiers — low, medium and critical. A weapon alarm has strict priority and can never be silenced by a lesser alert.

🎥

Recording & Torch

Record the live feed to internal storage with an in-app gallery, plus an on-device flashlight for low-light monitoring.

Under the hood

The recognition pipeline

Accuracy comes from a strict, ordered pipeline. The alignment stage is mandatory — an early prototype failed precisely because it skipped it.

▶ Face Detection — ML Kit finds faces + 5 landmarks
▶ Quality Gate — rejects too-small / too-tilted faces
▶ Alignment — warps the face to a canonical 160×160 crop mandatory
▶ FaceNet-512 — produces a 512-dimension embedding
▶ Cosine Matching — compares against enrolled faces with a margin
▶ Multi-Frame Voting — 3-of-4 frames agree for a stable verdict
Result: KNOWN + name UNKNOWN identifying…

By design

Privacy is structural, not a setting

The app is engineered so that sensitive data physically cannot leave the device.

🚫 No network capability

The INTERNET permission is deliberately absent — the app is incapable of transmitting data, not merely promising not to.

🧬 Biometrics stay local

Face embeddings live only in the on-device database and never leave the phone.

🔑 Hashed credentials

Operator passwords are stored as BCrypt hashes (cost 12), never plaintext, with a hashed one-time recovery code.

🛡️ Backups disabled

Private app data is excluded from device backup to protect biometric information.
